// GitLinq · Windows desktop

Git이 낯설어도,변경은 명확하게.

SVN에 익숙한 팀을 위한 Windows Git 클라이언트. 작성자와 제목으로 변경을 찾고, 취소 결과를 먼저 확인하세요.

// 01 · Workflow

찾고, 확인하고, 반영하기.

지금 필요한 변경에 집중할 수 있도록, 작업의 대상과 결과를 화면에서 확인합니다.

[01]

누가 무엇을 바꿨는지

작성자와 제목으로 변경 목록을 살펴보세요. 원하는 변경을 선택해 취소할 대상을 확인합니다.

[02]

되돌리기 전에 미리보기

선택한 변경의 취소 결과를 먼저 계산합니다. 확인 후 새 취소 커밋을 만들고 서버 반영 결과를 확인합니다. 겹치는 변경은 직접 해결이 필요한 상태로 안내합니다.

[03]

서버의 새 변경을 내 PC로

받을 내용을 확인한 뒤 깨끗한 작업 폴더를 업데이트합니다. 미커밋 수정이나 서로 갈라진 변경이 있으면 적용을 멈추고 안내합니다.

현재 개발 중

일상적인 새 변경 커밋과 앱 안에서의 직접 충돌 편집은 아직 제공하지 않습니다. 현재 프리뷰는 변경 조회·취소·서버 업데이트에 집중합니다.

// 02 · Getting started

내 환경에 맞게 시작하세요.

  • 설치하거나, 압축을 풀거나설치 파일은 현재 사용자 계정에 설치합니다. 무설치 ZIP은 폴더에 압축을 풀고 GitLinq.exe를 실행하세요.
  • Git은 자동으로 찾습니다이미 설치된 Git을 자동 탐지합니다. 설정에서 실행 파일을 직접 지정하거나 앱 안에서 Git을 내려받을 수 있습니다.
  • 인터넷이 제한된 PC에서도설정에서 지원되는 Git 배포 ZIP을 불러올 수 있습니다. GitLinq 무설치 ZIP과 Git 배포 ZIP은 서로 다른 파일입니다.

다운로드 전에 확인하세요

Windows x64와 Microsoft Edge WebView2 Runtime이 필요합니다. 무설치 ZIP에도 WebView2가 포함되어 있지 않습니다.

현재 배포는 코드 서명이 없는 프리뷰입니다. Windows가 알 수 없는 게시자 또는 SmartScreen 경고를 표시할 수 있습니다. 실행 전 배포 출처와 Release의 SHA256 파일을 확인하세요.
